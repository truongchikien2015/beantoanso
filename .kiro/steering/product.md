# Product

**Bé An Toàn Số** ("Digital Safety Kid") is a Vietnamese-language educational gamified web app that teaches primary school children (ages 6–12) how to use the Internet safely.

## Core Concept

Cùng Bé Kiên và Robot An Toàn học cách sử dụng Internet an toàn — children learn alongside two mascots: **Bé Kiên** (child learner) and **Robot An Toàn** (safety guide).

## Audience

- Primary students (ages 6–12) — main players
- Teachers — manage content for their classes via `/teacher`
- Admins — full system management via `/admin`

## Key Features

- **Quiz** — 10 random questions with voice answering and TTS read-aloud
- **Missions** — 5 story-based scenarios with branching choices
- **Classify** — drag-and-drop info classification game
- **Daily Challenge** — 1 question per day with streak tracking
- **Lessons** — 7 educational lessons with TTS
- **Journey Map** — visual progression with topic unlocks
- **Learning Paths** — 3 default paths (Cơ bản, Nâng cao, Toàn diện)
- **Leaderboard** — rankings with podium and CSV export
- **Certificates** — print-ready A4 landscape after completion
- **Admin/Teacher dashboards** — CRUD for questions, topics, paths, students; AI-assisted question generation

## Topics (Internet Safety)

stranger · phishing · password · privacy · behavior · screentime · badcontent

## Product Principles

- **Vietnamese-first** — all user-facing text must be in Vietnamese (vi)
- **Child-safe content** — AI-generated questions pass through a Vietnamese unsafe-term blocklist
- **Playful and accessible** — large buttons, friendly colors, animations, TTS for non-readers
- **Guest-friendly** — quick-play mode bypasses authentication
- **Gamified** — XP, levels (Tân binh → Truyền kỳ), badges, confetti celebrations
